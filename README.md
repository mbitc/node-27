# Node-27

Minimalistinis 27 MHz eksperimentinis ryšio mazgas naršyklėje.
Projektas orientuotas į CB / HF radijo logikos modeliavimą, signalų perdavimo eksperimentus, mazgų sąveiką ir edukacinį demonstravimą.

🌐 Demo: [node-27 live demo](https://mbitc.github.io/node-27/?utm_source=chatgpt.com)
📦 Repository: [node-27 GitHub repository](https://github.com/mbitc/node-27?utm_source=chatgpt.com)

---

## Overview

`node-27` yra lengvas browser-based projektas skirtas:

- eksperimentuoti su 27 MHz ryšio koncepcijomis,
- modeliuoti siųstuvo / imtuvo logiką,
- vizualizuoti radijo mazgų sąveiką,
- tirti jonosferinio atspindžio idėjas,
- kurti retro-tech / tactical UI atmosferą.

Projektas nėra skirtas realiam licencijuojamam ryšiui ar RF galios generavimui.
Tai edukacinis ir eksperimentinis programinis modelis.

# Running Locally

Klonuok repository:

```bash
git clone https://github.com/mbitc/node-27.git
```

Atidaryk katalogą:

```bash
cd node-27
```

Paleisk paprastą lokalų serverį:

```bash
python -m http.server
```

arba:

```bash
npx serve
```

Tada naršyklėje:

```text
http://localhost:8000
```
